============================================================
1. O QUE É A RIPCOM
============================================================
RIPCOM é a provedora própria de jogos autorais.
RR7 é o primeiro operador sandbox da RIPCOM.
Os jogos RIPCOM são produtos independentes e poderão ser integrados por outras plataformas.

============================================================
2. MODELO DE DESENVOLVIMENTO
============================================================
Fonte de verdade: GitHub.
Backend: Supabase + PostgreSQL + Edge Functions.
Validação: GitHub Actions + testes + TypeScript + build.
Lovable: opcional; o desenvolvimento não depende de créditos.

7. AUTENTICAÇÃO RSA
============================================================
Cada operador usa seu próprio par RSA.

Parceiro mantém:
PRIVATE KEY

RIPCOM armazena:
PUBLIC KEY

Headers:
X-Ripcom-Operator
X-Ripcom-Timestamp
X-Ripcom-Request-Id
X-Ripcom-Signature

Algoritmo:
RSA-SHA256 / RSASSA-PKCS1-v1_5

Canonical string:
METHOD\nPATH\nTIMESTAMP\nREQUEST_ID\nSHA256_HEX(BODY_EXATO)

28. SEGURANÇA OBRIGATÓRIA
============================================================
Private key nunca no frontend.
Private key nunca no banco RIPCOM.
Uma chave por operador.
Timestamp contra replay.
Request ID para idempotência.
Player recebe somente token temporário.
RLS protege tabelas administrativas.
Liquidação sensível somente via backend.
Sessões ficam vinculadas à release.
Chaves QA devem ser rotacionadas.
Provider frontend nunca recebe service_role.
CNPJ/dados empresariais ficam privados por padrão.
Dinheiro real não é habilitado por simples flag.
