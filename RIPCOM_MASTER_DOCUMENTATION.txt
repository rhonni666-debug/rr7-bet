3. ECLIPSE BONUS
============================================================
Gatilho: 3 scatters.
Prêmio: 8 rodadas grátis.
Retrigger: desabilitado nesta release.
Aposta nas free spins: mesma aposta que ativou o bônus.
Débito nas free spins: nenhum.
Ganhos: creditados normalmente no saldo DEMO.
Persistência: recarregar a página não apaga o bônus.

Fluxo:
2 scatters -> tease -> rolo decisivo desacelera -> fundo escurece -> sol aparece -> lua fecha o eclipse -> serpente sobe -> ECLIPSE BONUS -> 8 RODADAS GRÁTIS -> contador 8 a 0 -> total ganho.

============================================================
6. GREAT / BIG / MEGA WIN
============================================================
GREAT WIN = multiplicador >= 5x e < 10x.
BIG WIN = multiplicador >= 10x e < 25x.
MEGA WIN = multiplicador >= 25x.

A classificação é somente audiovisual.
Inclui partículas, anéis, texto animado, contador progressivo, som próprio e pausa temporária das free spins.

11. AUTENTICAÇÃO B2B
============================================================
Parceiro mantém PRIVATE KEY.
RIPCOM armazena PUBLIC KEY.

Headers:
X-Ripcom-Operator
X-Ripcom-Timestamp
X-Ripcom-Request-Id
X-Ripcom-Signature

Algoritmo: RSA-SHA256 / RSASSA-PKCS1-v1_5.
Canonical string:
METHOD\nPATH\nTIMESTAMP\nREQUEST_ID\nSHA256_HEX(BODY_EXATO)
