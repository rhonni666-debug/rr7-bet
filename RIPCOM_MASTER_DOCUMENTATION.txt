============================================================
1. RIPCOM
============================================================
RIPCOM = provedora própria e infraestrutura dos jogos.
RR7 = primeiro operador sandbox.
Jogos RIPCOM = produtos independentes distribuíveis para outras plataformas.
GitHub = fonte de verdade.
Supabase/PostgreSQL/Edge Functions = backend.
Lovable = opcional; o projeto não depende de créditos.

============================================================
2. ARQUITETURA
============================================================
Plataforma parceira -> RIPCOM B2B API -> sessão/release -> game runtime -> player standalone -> jogador.

Fluxo externo:
OPERADOR -> ripcom-b2b -> launch_url -> ripcom-provider standalone -> ripcom-player-runtime -> Eclipse Serpent.

5. ECLIPSE BONUS
============================================================
Gatilho: 3 scatters.
Prêmio: 8 rodadas grátis.
Retrigger: desabilitado nesta release.
Aposta nas free spins: mesma aposta que ativou o bônus.
Débito nas free spins: nenhum.
Ganhos: creditados normalmente no saldo DEMO.
Persistência: recarregar a página não apaga o bônus.

Fluxo visual:
2 scatters -> tease -> rolo decisivo desacelera -> fundo escurece -> sol aparece -> lua fecha o eclipse -> serpente sobe -> olhos brilham -> ECLIPSE BONUS -> 8 RODADAS GRÁTIS -> contador 8 a 0 -> total ganho.

6. ÁUDIO PROCEDURAL E JUICE VISUAL
============================================================
Arquivo de áudio:
ripcom-provider/src/game/audio.ts

O áudio é sintetizado no navegador com Web Audio API e não usa samples ou efeitos copiados de terceiros.

Eventos:
spin() = giro pago
freeSpin() = rodada grátis
tease() = suspense de quase bônus
bonusHit() = confirmação do Eclipse Bonus
win(multiplier) = vitória / Big Win / Mega Win
bonusComplete() = encerramento do bônus

O player possui botão para ativar/desativar som.
O navegador libera áudio após a primeira interação do usuário.

10. RUNTIME DO PLAYER
============================================================
Edge Function: ripcom-player-runtime
Base:
https://tndnqjbkfwongolorvjm.supabase.co/functions/v1/ripcom-player-runtime

Ações:
player_state = estado da sessão/saldo/config/bônus
player_spin = RNG server-side + liquidação + bônus
player_close = encerra sessão

O browser recebe somente token temporário.
Nunca recebe private key RSA ou service_role.

============================================================
11. AUTENTICAÇÃO B2B
============================================================
Parceiro mantém PRIVATE KEY.
RIPCOM armazena PUBLIC KEY.

Headers:
X-Ripcom-Operator
X-Ripcom-Timestamp
X-Ripcom-Request-Id
X-Ripcom-Signature

Algoritmo: RSA-SHA256 / RSASSA-PKCS1-v1_5.
Canonical string:
METHOD\nPATH\nTIMESTAMP\nREQUEST_ID\nSHA256_HEX(BODY_EXATO)
